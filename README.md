## About

I'm Oxford (Drishya Adhikari), a Grade 12 student from Kathmandu. I build things that sit between hardware and software: sensors that collect real-world data, and interfaces that turn that data into something people can act on.

I'm the Secretary of my school's Sci-Tech Guild, and I compete in hackathons as part of **Tridiots**, a three-person team. I also write poetry under the pen name Oxford.

## What I work on

| Area | What it looks like |
| --- | --- |
| **Embedded hardware** | Arduino-based sensor prototypes: motion (MPU6050), GPS, ultrasonic and RFID |
| **Web interfaces** | Dashboards and portfolios in React, Vite, Tailwind CSS and plain HTML/CSS/JS |
| **Applied problems** | Agriculture, road safety and emergency response, built under real hackathon time limits |

## Featured projects

| Project | What it does | Built with |
| --- | --- | --- |
| [**KrishiPath / KrishiTrust**](https://github.com/rbr-oxford/KrishiPath) | Sensors on a vehicle measure how produce is handled in transit and produce a Handling Reliability Score that farmers, lenders and insurers can rely on. Built with Tridiots. | React, Arduino, MPU6050, GPS, ultrasonic |
| [**RoadDNA**](https://github.com/rbr-oxford/RoadDNA) | A road intelligence platform that detects, analyzes and visualizes road conditions in real time. | JavaScript, Vite, Tailwind CSS |
| [**Portfolio**](https://github.com/rbr-oxford/rbr-oxford.github.io) | My personal site, hand-written with no frameworks: canvas particle background and scroll-triggered animations. | HTML, CSS, JavaScript |
